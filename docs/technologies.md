# Technologies

## Core Stack

- **Frontend**: [Next.js](https://nextjs.org) - The React framework for the web.
- **Database & Realtime**: [InstantDB](https://instantdb.com) - For real-time updates and database needs.
- **Hosting**: [Cloudflare](https://www.cloudflare.com) - Fast and secure hosting.

## UI & Styling

- **Styling**: [Mantine UI](https://mantine.dev) - Fully featured React component library.

## Services

- **Authentication**: [Clerk](https://clerk.com) - Complete user management key.
- **Analytics**: [PostHog](https://posthog.com) - Product analytics.
- **Error Monitoring**: [Sentry](https://sentry.io) - Application monitoring and error tracking.

## Utilities

- **Form Validation**: [Zod](https://zod.dev) - TypeScript-first schema declaration and validation.
- **Internationalization**: [next-intl](https://next-intl-docs.vercel.app) - Internationalization for Next.js.
